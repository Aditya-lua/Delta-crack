# Delta crack

Reverse-engineering workspace for the Delta Executor iOS application.

The reconstructed iOS source, analysis scripts, reports, recovered assets, and
function-by-function lifts are under [`iOS/`](iOS/).

This repository is an analysis artifact, not Delta's original source tree.
Optimized native binaries do not preserve every original identifier, type,
comment, or build setting, so reconstructed files distinguish evidence-based
source-like recovery from exact upstream source.

Large app binaries, IPA packages, transient emulator dumps, credentials, and
local progress checkpoints are intentionally excluded from Git.
